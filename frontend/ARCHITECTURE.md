# Архитектура frontend

## Стек

- Create React App (`react-scripts`), без Vite;
- React;
- Tailwind CSS;
- Zustand для клиентского и сессионного состояния;
- React Router для маршрутизации;
- Axios для HTTP-клиента;
- Lucide React для единого набора SVG-иконок;
- Jest и Testing Library из CRA.

## Правило зависимостей

Допустимое направление импортов:

`app → pages → widgets → features → entities → shared`

Нижний слой не импортирует верхний. Функциональный модуль не обращается напрямую к внутренним файлам другого модуля — только к его публичному `index.js`.

## Назначение слоёв

- `app` — запуск приложения, глобальные провайдеры и конфигурация маршрутов;
- `pages` — компоненты URL-страниц, собирающие экран из виджетов и функций;
- `widgets` — крупные самостоятельные блоки: учебный плеер, карта знаний, аналитика;
- `features` — пользовательские действия и законченные возможности;
- `entities` — модели предметной области и их компактные UI-представления;
- `components` — общие композиционные компоненты макета и навигации;
- `shared` — API-клиент, конфигурация, утилиты, базовые UI-компоненты и типы;
- `assets` — изображения, иконки и локальные шрифты.

## Состояние

Zustand применяется только для состояния, которое разделяют несколько удалённых частей интерфейса:

- текущая сессия и роль;
- настройки доступности и языка;
- черновик диагностики;
- активная учебная сессия;
- уведомления приложения.

Серверные данные не дублируются без необходимости в глобальном store. Локальное состояние формы остаётся внутри её функции.

## План маршрутов

### Публичные

- `/` — главная;
- `/about` — как работает персонализация;
- `/accessibility` — возможности доступности;
- `/login`, `/register` — авторизация.

### Ученик

- `/student/onboarding` — профиль, класс, предмет и цель;
- `/student/diagnostic` — диагностика;
- `/student/dashboard` — шаг дня, цели и прогресс;
- `/student/path` — персональный маршрут;
- `/student/knowledge-map` — созвездие знаний;
- `/student/learn/:moduleId` — учебный модуль;
- `/student/task/:taskId` — задание;
- `/student/progress` — детальная аналитика;
- `/student/achievements` — достижения;
- `/student/settings` — язык и доступность.

### Учитель и администратор

- `/teacher/dashboard` — сводка класса;
- `/teacher/classes/:classId` — ученики и проблемные навыки;
- `/teacher/students/:studentId` — прогресс ученика;
- `/teacher/content` — темы и материалы;
- `/teacher/content/new` — создание материала;
- `/teacher/assignments` — назначения и дедлайны.

## Правила файлов

- один основной React-компонент на файл;
- тест лежит рядом с тестируемым модулем;
- экспорт наружу идёт через `index.js` модуля;
- в компонентах нет сырых URL API и цветовых hex-значений;
- UI-компоненты не знают о формате ответа backend;
- страницы не содержат сложную бизнес-логику;
- имена компонентов — PascalCase, хуков — `use...`, store — `...Store`;
- ленивое подключение страниц выполняется на уровне маршрутов.

## Переменные окружения

- `REACT_APP_API_URL` — базовый URL backend;
- `REACT_APP_AI_STREAM_URL` — URL потоковых AI-ответов, если отличается;
- `REACT_APP_DEFAULT_LOCALE` — язык по умолчанию;
- `REACT_APP_ENABLE_MOCKS` — включение mock-данных для демо.
