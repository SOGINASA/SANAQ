# Backend

Backend ещё не реализован. Согласованный список модулей, REST-маршрутов, ролей, моделей данных и требований к AI находится в [API_ROUTES.md](API_ROUTES.md).

Рекомендуемая стратегия для хакатона — модульный монолит с чёткими доменными границами. Это быстрее и надёжнее для MVP, чем сеть отдельных сервисов, но позволяет позднее вынести AI, уведомления и аналитику в самостоятельные сервисы.
