# SANAQ

SANAQ — AI-платформа персонального обучения для школьников 7–12 классов Казахстана. Проект создаётся для трека Social Impact на Future Minds Hackathon 2026.

Платформа выявляет пробелы в знаниях, строит персональный учебный маршрут, визуализирует освоение навыков и помогает ученику разбирать ошибки вместе с AI-спутником SANA. Учитель получает инструменты создания учебного контента, назначения заданий и контроля прогресса класса.

Подробное описание продукта: [docs/PRODUCT_CONCEPT.md](docs/PRODUCT_CONCEPT.md).

## Состояние проекта на 18 августа 2026

Проект находится в состоянии функционального MVP. Основные учебные сценарии связаны с backend API, интерфейс адаптируется под мобильные устройства, а значительная часть приложения переведена на русский, казахский и английский языки.

### Что уже сделано

#### Учебный модуль ученика

- регистрация, авторизация и разделение доступа по ролям;
- диагностика знаний и сохранение её прогресса;
- карта знаний и персональный учебный маршрут;
- учебные модули, задания, проверка ответов и объяснение ошибок;
- сохранение прогресса урока и продолжение с последнего шага;
- адаптивное отображение сложности задания;
- задания с одиночным и множественным выбором, числовым ответом, сопоставлением, сортировкой и заполнением пропусков;
- экран прогресса, слабые навыки и интервальные напоминания;
- AI-спутник SANA;
- настройки доступности и озвучивание интерфейса через Speech Synthesis API.

#### Кабинет учителя и редактор контента

- сводка класса, список учеников, поиск и тепловая карта навыков;
- профиль ученика с деталями прогресса и комментариями учителя;
- создание назначений, выбор класса, модуля и срока выполнения;
- экспорт списка учеников в CSV;
- создание и редактирование учебных модулей и заданий;
- предпросмотр учебного материала перед публикацией;
- локальное автосохранение черновика редактора;
- поддержка всех реализованных типов заданий в редакторе;
- уведомления ученикам о назначениях и комментариях.

#### Интерфейс и дизайн-система

- единая дизайн-система SANAQ на Tailwind CSS;
- общие компоненты `Button`, `Card`, `Dialog`, `Input`, `ProgressBar`, `Skeleton`, `StatusToast` и `Tabs`;
- семантические состояния ошибок, предупреждений, успеха и пустых экранов;
- отдельная страница `/ui-kit` для проверки компонентов;
- адаптивная навигация для desktop и mobile;
- адаптация длинных переводов, форм, таблиц и карточек под узкие экраны;
- управление размером текста, контрастом, снижением анимации и озвучиванием;
- синхронизация действующего интерфейса с [design-system/sanaq/MASTER.md](design-system/sanaq/MASTER.md).

#### Локализация

- собственный модуль i18n без внешней зависимости;
- русский, казахский и английский языки;
- сохранение выбранного языка;
- локализованы публичные страницы, авторизация, основная навигация, настройки, учебные экраны и ключевые страницы учителя;
- локализованы диалоги, уведомления интерфейса, пустые состояния, подписи доступности и CSV-заголовки.

#### Backend и инфраструктура

- Flask application factory, JWT-аутентификация и ролевая модель;
- API диагностики, каталога, учебного маршрута, заданий, прогресса, контента, назначений и уведомлений;
- модели знаний, попыток, комментариев учителя и учебного контента;
- конфигурация SQLite для локальной разработки и PostgreSQL для production-контура;
- Docker Compose для React/Nginx, Flask/Gunicorn, PostgreSQL, PathNet и Ollama/Qwen3;
- интеграционные тесты основных backend-сценариев.

## Локальный запуск

### Frontend

```bash
cd frontend
npm install
npm start
```

В development запросы `/api/v1` автоматически проксируются Create React App на
Flask по адресу `http://127.0.0.1:8000`. После изменения `package.json` frontend
нужно перезапустить.

Production-сборка и тесты:

```bash
cd frontend
npm test -- --watchAll=false
npm run build
```

### Backend

```bash
cd backend
python -m venv .venv
python -m pip install -r requirements.txt
python app.py
```

API запускается на `http://localhost:8000/api/v1`.

Запуск тестов:

```bash
cd backend
python -m pytest
```

## Запуск MVP через Docker

```bash
cp .env.production.example .env
# Заменить значения change-me в .env.
docker compose up -d postgres ollama
docker compose exec ollama ollama pull qwen3:8b
docker compose up -d --build backend frontend
```

Приложение будет доступно на `http://localhost`, API — через тот же домен по `/api/v1`. Полная инструкция: [docs/MVP_DEPLOYMENT.md](docs/MVP_DEPLOYMENT.md).
